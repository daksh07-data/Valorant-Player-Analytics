# Valorant Player Analytics Dashboard 🎮

## Project Overview
This project analyzes Valorant player performance data using Excel, SQL, and Power BI.

The dashboard provides insights into:
- Total kills
- Total matches
- Total damage
- Average headshots by rank
- Rank-wise player performance

## Tools Used
- Excel
- SQL (MySQL)
- Power BI

## Features
- Interactive dashboard
- KPI cards
- Rank-based analysis
- Gaming-themed dashboard design
- SQL analytical queries
